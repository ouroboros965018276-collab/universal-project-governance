# RC19 native independent A5: full callback audit

A5 completed its preregistered 32 fresh calls, with all 32 stored strict artifact outcomes passing and 439,193 CLI-reported tokens. Its independent full-callback time and quality gate **PASS** is confirmed. This establishes the registered artifact-task timing result; it does not establish joint token and time benefit, satisfy the separate B gate, or establish formal qualification.

The [public protocol](../evolution/protocol/rc19-native-independent-a-v5.json) has SHA-256 `c54f5a29219cecf2d7da44ac86cc0378d980731dea364d981590dcb318320623`; its executable private registration has canonical SHA-256 `bfa1a66b425f7b6081db3d7997cea2322e652b3fd8852816c217a54c26950c6c`. The completed private run has raw SHA-256 `8ad99c71b798e69d00247016f9eb7708a6cd65adbffe72957b761e0bb1add67a`. The protocol's immutable `PREPARED-NOT-DISPATCH-AUTHORIZED` field describes its preparation state; the separately retained run records actual completion.

The control callback and minimal module dependencies are exact Git bytes from RC18 `29cf112b4629d6b90504b079e95a5370c206a4cb`; treatment uses `1f286516896a83b1bf58a87fc362080b01ea778f`. Four isolated persistent workers each made eight calls. Both arms used the same operator-selected treatment-release grader, SHA-256 `27af694887318e9eadd22c129a34616f1c34899b27adc0dbf8fbede2279afb5e`, through the unchanged public native runner API. The audit verified its bytes without invoking the grader again or changing scores.

Two requested OpenAI model IDs, `gpt-6-sol` and `gpt-6-luna`, used catalog-listed low effort on eight parameterized artifact fixtures from four known families. Each worker encountered four distinct contexts before four new fixture instances with the same respective contexts. Registered seed 19012 fixed matched task order and balanced condition order. The bootstrap uses 4,000 draws of whole family blocks, preserving both models and cold/repeat pairs together. The four-family interval describes this experiment's limited scope; it establishes neither new-family generality nor multiple-provider qualification.

Treatment's eight first-context preparations were cache misses and eight repeated-context preparations were hits. Repeated preparations recorded zero compilation and planning time while retaining positive cache and capability verification time. Historical control provides no equivalent local phase fields, so these were not invented. “Cold” describes the client preparation context; OS and provider caches were uncontrolled. The pooled callback improvement is about 21.49%, but the experiment cannot assign that entire difference to local caching: CLI-phase variation also contributed.

The token interval crosses one, and Luna regressed by about 1.2071%. The first Sol control used 16,488 tokens, compared with roughly 13,400–13,900 for other calls. Its excess has no demonstrated optimization cause. All observations remain in the pooled and stratified results; no outlier or warning sample was removed. Token counts include reported cached and reasoning usage as recorded; they are not provider billing statements. Internal model selection, billing and stronger process isolation remain unverified.

The independent raw audit checked 1,152 assertions: source/compiler/license/runtime and grader bindings to Git, worker manifests and exact task order, actual Skill/plan/task prompt bytes without hidden grader checks, all output schemas, original grade-to-final-text bindings, and static positive JSON/Python-AST/text contracts without executing application code. It confirmed 32 distinct actual CLI thread receipts, 32 distinct harness request identities, 32 distinct durable receipts, and consistent usage across raw completed-turn events, native results, worker messages, observations and budget records. All streams contained exactly one `thread.started`, `turn.started`, final `agent_message` and `turn.completed`; there were no tool, failure or error events. These checks did not rerun scoring or modify the frozen records.

Both release callbacks ran under the same child-only HTTP instrumentation. Every actual argv exactly matched the frozen native argv plus eight registered overrides: provider ID, OpenAI name, Responses wire API, existing OpenAI authentication requirement, disabled WebSockets, zero request retries, zero stream retries and disabled unbounded connection retries. CLI and instrumentation-source hashes were verified. This is a shared transport scaffold, rather than a claim that RC18's original transport was reproduced. No host configuration or login material was changed. Raw streams contained no reconnection event, but completed-turn receipts and argv do not attest provider billing.

All 32 CLI stderr files contained the existing PowerShell shell-snapshot unsupported warning. Sample 4, Luna control on the first dependency context, additionally reported an analytics-event upload HTTP 503 warning from `codex_analytics::client`; its inference stream still completed with known usage and exit zero. All four worker stderr files were empty and workers exited zero. The warning is retained and distinguished from an inference failure. Host load was not attested; precise overlap with another review near the final 3.1 seconds is unknown, and all samples are retained.

The [sanitized audit receipt](../audits/rc19-native-independent-a-v5.audit.json) records hashes, individual usage/timing evidence, full per-model and context statistics, warning taxonomy and preservation limits. Raw CLI/thread identities, absolute host paths, private prompts and fixture contents remain local. A5 itself has 32 known calls and zero unknown calls; unrelated earlier, later and route-diagnostic calls are outside this experiment. Formal qualification remains **UNASSESSED**, and the independent B joint token/time requirements remain unchanged.
