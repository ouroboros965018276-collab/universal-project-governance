The third dispatch, Luna with the child-no-proxy candidate, failed with `Connection failed: error sending request` and no completed turn or usage. Its cost remains unknown. The fourth planned call was not dispatched. The durable `NO_REPLAY` fence remains intact. The audit **PASS-UNKNOWN-FAILURE-RECONCILED** means the evidence and accounting reconcile; it does not mean the route diagnostic succeeded.

Both routes shared low effort, the same fixed public JSON prompt and schema, read-only/ephemeral execution, ignored user configuration, skipped host Skill discovery, disabled optional tools, and the same eight HTTP profile overrides. The common startup trio was `features.code_mode.enabled=false`, `features.code_mode_host=true`, and `suppress_unstable_features_warning=true`. The already installed official host dependency was registered by hash; this diagnostic did not install anything or attest actual child-host executable selection. No tool events were observed.

Only the child-no-proxy condition added `features.respect_system_proxy=false`, `features.system_proxy_fallback=false` and `NO_PROXY=*` to a copied child environment. The existing-profile condition inherited its environment unchanged. Each actual receipt records absent nonempty `HTTP_PROXY`, `HTTPS_PROXY` and `ALL_PROXY`, with `NO_PROXY` present. The full inherited environment, its sensitive values and actual stdin bytes were intentionally not persisted. Frozen harness source, the public prompt hash, exact argv and strategy receipts bind the intended launch; they do not independently attest the effective proxy, OS/TUN route or absence of a host change by another process.

The raw Sol streams each contain exactly one thread start, turn start, final agent message and completed-turn usage. The Luna stream contains a unique thread start and turn start followed by `error` and `turn.failed`, both with the same generic connection-failure message; it contains no `turn.completed`, final answer or usage. All three stderr files contain only the existing PowerShell shell-snapshot unsupported warning. Three actual thread identities and three harness request identities are unique. Original labels, raw bytes, pending records, receipts and the unknown fence were preserved; the auditor invoked neither the collector nor a grader or model.
