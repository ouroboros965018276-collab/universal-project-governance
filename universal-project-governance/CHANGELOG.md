# Skill Changelog

## 2.0.0-rc.3 — 2026-10-02

Self-Protecting Governance + Feedback Driven Governance.

- Adds tamper-evident protect-all integrity checks for the installed Skill.
- Makes ordinary project tasks explicitly unable to modify the Skill contract.
- Adds adaptive report policy with minimal, standard, and evaluation modes.
- Adds current Handoff Snapshot semantics for real agent/engineer boundaries.
- Adds Agent Execution Audit and governance feedback for qualifying/evaluation tasks.
- Adds bounded report retention so governance evidence does not become governance debt.
- Adds safe evidence export for external review without exporting project source code by default.
- Preserves the original single-Skill, model-agnostic, project-agnostic governance concept.
