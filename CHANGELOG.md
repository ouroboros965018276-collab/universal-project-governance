# Changelog

## 2.0.0-rc.4 — 2026-10-03

Compiled Governance Architecture.

- Replaces the RC3 document-oriented runtime with a generated bounded runtime.
- Adds one canonical typed governance model and stable policy IDs.
- Adds rule-graph dependency closure and deterministic static analysis.
- Adds typed task contexts and task-specific Governance Plan compilation.
- Adds risk-adaptive report/handoff selection.
- Adds project capability profiles that activate existing policies without redefining them.
- Adds schema-first handoff, execution, feedback, and audit state.
- Adds deterministic rendering, compaction, and evidence export.
- Adds compiler drift protection and generated-runtime integrity manifest.
- Adds hard governance-complexity budgets to CI.
- Removes the install-time `references/` and Markdown-template trees from the runtime.
- Preserves the original project-governance concept: implementation, cleanup, technical-debt control, current truth, evidence, and handoff remain one lifecycle.
