This candidate prepares one DEVELOPMENT study: 18 paired blocks, 54 workflows,
66 actor roles, DeepSeek/MiMo, and RC19/attention/full arms. It is not an
independent holdout, qualification, efficacy result, promotion or installed Skill.
Actual roots, qualification receipts, independent closure and launch grants remain
UNBOUND. Finite post-audit manual and analysis grants are source-frozen; their
entries still require the original successful first-audit/exit/seal/lock bridges. No API, key, project, Docker, Git or actual reader has run here.

`prepare_bundle.py` derives tasks from frozen nine-family v7 data, constructs the
fixed seeded schedule and six review panels, verifies the two 18-file packages,
and binds task/context/system/entry bytes. Default plans are explicit unusable
stubs. A separately authorized preparation invocation can run the two frozen
trusted planners; it cannot run benchmark code or load credentials. Attention
reuses RC19's plan and Skill plus its fixed single sentence. Per-actor planners
still execute against that actor's actual context during a future registered run.

`run_once.py` owns one sole-parent process. The parent owns the Job and API child;
`launch.py` activates `collector.py`, which enables the shared C3-derived
collector/raw reader only in memory and restores their disabled state in finally.
The one shared ledger persists reservations before its lazy credential callback.
Every actor retains 180 work seconds, 12 requests, 32 tools, minimum 15 seconds
to dispatch, and at most 600 accounting-only seconds for the same inflight tail.
The strict outer cap is 54840 seconds from the supervisor's first setup, before
admission. The nested parent/collector origins cannot extend that earlier cap.

Each workflow owns one physical project. A receiver obtains its verified current
bytes and original protected baseline, without source chat or intended patches.
The independent `first_auditor.py` replays only the latest disk stage per workflow,
including source history, and verifies every occurred native/accounting prefix.
Missing or unknown evidence cannot pass. A controlled source is completion-ungraded;
all its occurred serious safety/scope/contract/fact defects remain reviewable.
`audit_once.py` owns exactly one external first-auditor process, uses the same
bounded generic reaper, and publishes its observed exit and seal qualification
in a separate registered control root. Its 1200-second cap and elapsed audit
cost are separate from the primary paired operational wall.

`source-map.json` and reader pins are exactly its `shared/` subview, enforced by
common admission. They preserve C3's original HERE-relative path interpretation.

620467… and its original 18-file integrity manifest. RC19 version/bytes are pinned;

The cost boundary includes first setup, native/tool work, same-request settlement,
raw checking, workflow publication and shared operational persistence. The outer

`frozen-panel-assignment.json` assigns six independent fresh contexts, each receiving

independent owned-process exit-zero bridge, not a pre-publication report alone.
