# RC5 Qualification Plane

This directory is repository-only. It does **not** ship in the installed Skill.

RC5 asks one question: does Universal Project Governance causally improve real agent engineering behavior enough to justify its cost?

The governance runtime is frozen. Qualification uses fresh paired trials, executable repository labs, deterministic outcome grading, blinded semantic review only where needed, cross-agent handoff experiments, trigger activation tests, mutation-based evaluator sensitivity, overhead telemetry, preregistered thresholds, and immutable result rounds.

## Experimental arms

- **A0** — no Skill baseline.
- **A1** — attention-matched generic engineering control.
- **A2** — full UPG treatment.
- **K** — kernel-only diagnostic ablation, used only when attribution is needed.

## Evidence policy

Outcome evidence outranks self-description. Deterministic repository/test failures cannot be overruled by an LLM judge. Private chain-of-thought is neither requested nor stored.

Raw traces are not committed by default. Completed qualification rounds commit manifests, hashes, aggregates, and summaries; raw traces stay in controlled artifacts/evidence storage.

No result file is created until a real trial produces evidence.
